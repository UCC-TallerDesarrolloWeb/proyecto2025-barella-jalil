## 🧾 Descripción del Proyecto
**PROCRAFT PARTS** es un sitio web moderno orientado a la **instalación profesional**, **asesoramiento** e **importación de accesorios** para autos y camionetas. Incluye portada, páginas informativas, galería de proyectos y un formulario de solicitud de asesoramiento.

### 🎯 Objetivo
Aplicar buenas prácticas de **HTML5, CSS3 y JavaScript (ES6)** para construir un sitio responsive, accesible y con una identidad visual consistente (azul + naranja).

---

## 🧱 Contenido del Sitio
- **Inicio (`index.html`)**: hero, llamada a la acción y accesos a secciones.
- **Quiénes Somos (`quienes.html`)**: enfoque del taller y propuesta de valor.
- **Servicios (`servicios.html`)**: tarjetas de *Instalación*, *Asesoramiento* e *Importación*.
  - **Detalle de Servicio**: `servicio-instalacion.html`, `servicio-asesoramiento.html`, `servicio-importacion.html`.
- **Proyectos (`proyectos.html`)**: galería responsive (layout masonry) con imágenes/video.
- **Solicitar Asesoramiento (`asesoramiento.html`)**: formulario validado en cliente.

---

## 💻 Tecnologías Utilizadas

| Tecnología       | Uso Principal                                |
|------------------|-----------------------------------------------|
| **HTML5**        | Estructura semántica                          |
| **CSS3**         | Layout responsive (Flex/Grid), estilos y UI   |

Recursos: **Google Fonts (Montserrat, Bebas Neue)**, íconos SVG, media responsive.
